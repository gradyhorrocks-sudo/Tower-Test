GITHUB PAGES:
1. Create a GitHub account if needed.
2. Create a new PUBLIC repository, e.g. tower-registry.
3. Upload ALL files from this folder to the root of the repository.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose main and /(root), then Save.
7. GitHub will provide an HTTPS Pages URL.
8. Open that URL in Safari.
9. Safari Share > Add to Home Screen > Add.

PIN:

Each new browser/app session requires the PIN.
This is an app-level lock only. GitHub Pages remains public static hosting.
